# 人工考察阅读指南

## 首页与全局导航

打开阅读器根地址先进入首页，查看应用用途与资料规模。顶部始终保留「首页」「阅读」和全文检索框；可从任意页面输入关键词直接查询，留空点击「全文检索」则打开独立检索页。检索已移出右侧考察栏。

首页说明下方提供「PRTS 泰拉年表」及 Wiki 链接，用于外部人工参考；已从阅读侧栏移出。原有的玩家整理、推测与未定时间说明保留。

点击首页「继续阅读」或顶部「阅读」回到上次章节与所选段落；直接打开带章节 / 段落的链接仍优先定位原文。阅读期间点击「首页」不会清除阅读位置、笔记或外观设置。

首页说明由项目统一维护，不支持在浏览器中编辑。维护者直接修改 src/pages/index.astro 中的标题、简介和说明区块，重新发布即可更新。

## 剧情版本与更新

本站发布固定数据快照；版本信息可在「来源与版本」查看。维护者更新锁定来源并重新构建发布后，刷新页面即可读取新快照。访客无法安装或修改共享剧情数据。

笔记与阅读位置按快照分别保存，请在更新、切换浏览器或清理站点数据前导出备份。全文检索首次需要下载索引；后台线程处理查询，结果可分页并展开上下文。立绘来自固定版本的 GitHub 资源，网络与频率限制可能影响图片加载。

## 推荐走查

1. 用左侧目录检索找到你熟悉的一篇主线或活动，先看正文，再切换“正文与脚本指令”。注意一段对白前后有哪些背景、立绘和转场记录。
2. 点击某段，对照右侧源记录与 JSON Pointer，观察标签、正文排版标记和资源字段。`#i` 为数组下标，“源 n”为上游 id。
3. 使用发言标签筛选，只检查文本中现成的称呼，不据此假定是唯一角色；用篇内查找比较匿名与具名发言。
4. 对含选项章节核对 Decision / Predicate 与 targetLine。阅读器展示全部分支，选择按钮只滚动定位；OPTIONTRACE=false 的 19 篇禁用跳转。
5. 在页面顶部“全文检索”搜索明确的称谓、地名或时间原词。结果定位原段落并清除会遮挡该段的筛选。检索采用不区分大小写的连续子串，不使用分词、向量检索或模型。
6. 观察写入笔记，可记录“同一称谓是否多指”“字幕是否正文”“源记录是否丢文”等待核实问题；收藏原文位置。定期导出 JSON，可在同快照导入合并。
7. 按需展开游戏简介/上游已有摘要；避免先读摘要影响对源文的判断。侧边栏已移除手动摘要生成。打开 PRTS 年表进行人工对照，分别核对原始时间表达、编者推测与出处。

## 专注阅读、键盘与续读

- 点击正文外观工具栏的「专注阅读」，收起左右侧栏并居中显示正文；保留紧凑立绘卡片。宽屏卡片位于右侧留白区域，窄屏成为正文上方的小型悬浮预览。按 Esc 或左下角「退出专注」恢复侧栏；专注状态随外观设置保存。
- 点击一条文本后，用 ↑ / ↓ 切换当前筛选中可见的非空对白、旁白和文本记录，同时选中、滚动定位并更新立绘。跳过空白、脚本指令、选项与分支标记；不会自动选择分支，也不会自动跨章。没有选中记录时从第一条可见文本开始。
- 搜索框、笔记、下拉框和可编辑区域保留原来的键盘行为；打开来源弹窗时不启用阅读导航。按键带 Ctrl / Alt / Shift / Meta 修饰或正在输入法组字时也不接管。
- 点击或键盘选中段落时，立即保存章节 ID、段落数组下标和源文件哈希。重新打开应用后，点击首页「继续阅读」，恢复该章节与段落、滚动到正文并恢复立绘；保留之前的章节级历史作为兼容回退。
- 明确包含章节和段落的 URL 优先于历史位置；仅有章节的链接只恢复同章的位置。数据快照或源文件哈希不一致时，不将旧下标强行应用到新文本。
- 阅读位置保存在当前浏览器、当前 origin（协议、主机、端口）的 localStorage，与笔记使用独立的存储键。换端口、换浏览器或清理站点数据会影响恢复；保存的是最后选中的段落，不是仅靠滚轮移动后的像素位置。

## 阅读显示限制

阅读外观：右上角可切换白天 / 夜间模式，首次打开默认暖白纸色。正文下方工具区可选「霞鹜文楷」「书卷宋体」「清晰黑体」，以及标准 18 px / 大字 21 px 和紧凑模式。紧凑模式缩小行距与段落留白，不缩小所选字号。外观设置在当前浏览器保存，刷新后恢复。霞鹜文楷随项目离线加载，宋体 / 黑体使用系统字体栈；个别未覆盖的字由系统字体补齐。源 JSON 保持等宽字体。

- “上一篇/下一篇”仅在同目录的源序号内移动；无序号章节按路径排列。活动开放时间排序仅用于资料定位。
- 发言标签筛选会隐藏无标签旁白/指令；请用“清除筛选”恢复上下文。
- 全库检索覆盖当前导入的全部剧情及可检索文本记录（实际数量以首页和查询结果为准），支持 1–100 字符的连续子串，不区分大小写。可按正文 / 选项、发言标签或两者查询；不搜索上游摘要、其他 excel 表或图片内容。
- 页面顶部的「全文检索」打开独立查询页，专注阅读时也可直接使用；返回阅读时保留专注设置。查询返回命中篇章总数、行记录总数、每篇命中数；在「关键词所在篇章」中选定某篇可只看该篇命中行。每页 50 条，可连续翻页查看全部结果，已移除原来的前 100 条限制。
- 结果按资料的源文件枚举与记录顺序显示，不是相关性或世界时间排序。同一记录重复出现关键词只计一次命中。每条显示目录 / 标题 / 标签、数组下标、源行号、JSON Pointer 和成员路径；点击回到对应原文段落。
- 点击结果后，正文与发言标签中的关键词都会高亮，同时保留整篇上下文。正文顶部会显示当前定位关键词，可点击「清除关键词高亮」取消；通过目录或上一篇 / 下一篇打开章节时也会清除。该定位高亮不保存到阅读历史。
- 每条结果下可「展开命中行前后文」：首次按需读取前后各 3 条可读记录，可扩展至各 8 条、20 条，篇章边界处显示实际条数。命中行有独立标识，点击任意上下文行可跳转原文并保留关键词高亮。上下文跳过无文本的演出指令，保留选项与分支标记；源文件中的相邻记录可能属于互斥分支，不代表同一游玩路线。
- 立绘只展示源记录明确引用的资源；无引用时清空预览。背景、音频和游戏动画不播放；没有自动分支执行或世界时间线。
- 笔记与出处收起时，点击立绘卡片右上角的百分比，按 100% → 125% → 150% → 200% 循环调整大小。比例保存在当前浏览器，刷新页面或重新打开阅读器后自动恢复；展开笔记时使用原来的预览尺寸并隐藏此按钮，收起后恢复所选比例。
- 点击已加载的立绘可打开图片查看器。支持按钮、滚轮或加减键缩放、拖动查看、适应窗口及原始尺寸；下方显示脚本的 `figure_art`、成员路径和源记录位置。点击右上角关闭或按 Esc，回到原来的阅读位置与笔记面板状态。
- 存在上游格式差异和转换局限。保留的 raw 是发布包 JSON，不是 TXT；“原文”在界面中指该 JSON 的文本字段。
- 笔记自动在失焦/切段时保存，也可点击保存。清空内容且取消收藏后该段不再出现在记录列表。未提供云同步。
- 更换服务端口改变浏览器 origin，localStorage 不共享；先导出，再在新地址导入。不同快照拒绝混入，避免笔记错位。
- 小屏时右栏位于主栏下方；在桌面宽窗口中可同时看到三栏。

## 故障排查

缺少数据：运行 `python scripts/bootstrap.py`。端口占用：换用 `python scripts/serve.py --port 8767`；Windows 启动脚本可传 `-Port 8767`。文件不能直接通过 `file://` 打开，因为章节使用 fetch 加载；需要本地服务。网络请求失败时可稍后重试，已有本地数据仍可使用。
